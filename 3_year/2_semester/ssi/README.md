# Information Systems Security (SSI)

This folder contains the materials, exercises, and projects for the Information Systems Security course.

## Overview
This repository serves as a workspace for the Information Systems Security (SSI) course, encompassing weekly lab sessions, security exercises, and the final project. It covers practical applications of security concepts including cryptography, memory safety, and secure communication protocols.

## Tech Stack
Based on the course materials, the primary technologies used include:
- **Languages:** Python, C, Bash
- **Topics:** Cryptography, Memory Vulnerabilities, Secure Protocols, Web Security
