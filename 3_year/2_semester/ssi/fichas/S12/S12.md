# Exercício 5
1. **Causa comum:** Mistura entre dados (input) e instruções de controlo. O sistema interpreta input como código executável.
2. **Validação insuficiente:** Facilmente contornável por evasão ou *encoding*. Trata os sintomas, mas não resolve a vulnerabilidade estrutural.
3. **Parametrização:** Isola o input, forçando o processamento estrito como dado (literal).
   **Privilégio Mínimo:** Restringe permissões, limitando o raio de impacto caso o ataque tenha sucesso.
4. **Buffer Overflow:** Corrupção física e contígua (sequencial) da memória adjacente.
   **Format String:** Acesso não-contíguo; permite leitura/escrita arbitrária usando especificadores variádicos (`%x`, `%n`).
