Question 1:
stress-ng --mq 0 -t 30s --timeout 1m --metrics --times --perf
generates the highest level of kernel activity between all the commands used (83.12%)
this effect is produced because every message sent or received requires an expensive 
system call and context switching to move data between processes.

Question 2:
The memory test has high CPU utilization because the processor must constantly execute 
instructions to write data to RAM and manage the "page faults" triggered when the kernel 
allocates physical memory addresses.
