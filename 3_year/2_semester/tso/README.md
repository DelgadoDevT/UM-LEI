# Operating Systems Technologies (TSO)

This folder contains the materials, exercises, and projects for the Operating Systems Technologies course.

## Overview
This repository serves as a workspace for the Operating Systems Technologies (TSO) course, encompassing weekly lab sessions (fichas) and the final project. It covers practical applications of operating systems concepts including file systems (FUSE), eBPF (Extended Berkeley Packet Filter) tracing and profiling, and system performance analysis.

## Tech Stack
Based on the course materials, the primary technologies used include:
- **Languages:** C, Bash, eBPF
- **Topics:** File Systems (FUSE), eBPF, System Tracing, Performance Analysis
